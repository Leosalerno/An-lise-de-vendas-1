# 📊 Sistema de Análise de Vendas

Projeto desenvolvido em Java com foco em manipulação de arquivos e uso de Stream API, realizando análises sobre dados de vendas a partir de um arquivo `.csv`.

---

## 🚀 Funcionalidades

* Leitura de arquivo contendo dados de vendas
* Armazenamento das vendas em lista
* Cálculo do preço médio por venda
* Exibição das 5 maiores vendas (preço médio) de 2016
* Cálculo do valor total vendido por um vendedor específico em meses determinados

---

## 🧠 Conceitos aplicados

* Programação Orientada a Objetos (POO)
* Manipulação de arquivos (`FileReader`, `BufferedReader`)
* Expressões lambda
* Stream API (`filter`, `sorted`, `map`, `reduce`)
* Listas (`List`)

---

## 💻 Tecnologias

* Java
* Git & GitHub

---

## 📂 Estrutura dos dados

O arquivo de entrada deve seguir o formato:

```
mês,ano,vendedor,quantidade,total
```

### Exemplo:
```
1,2016,Logan,25,21099.27
```
